# MONTHLY SYSTEM AUDIT — the system maintains itself

_Auto-run every 30 days by `system_audit.py`. Owner involved ONLY for money/major decisions._

## Checks
1. **MCPs** — outdated / need upgrade (flagged from config).
2. **Job sources** — dead endpoints or changed URLs (pinged; dead ones disabled).
3. **GitHub repos** in `/skills` — new releases worth pulling (auto-merged if free).
4. **Techniques** in `/skills/techniques` — superseded by better ops-found methods.

## Rule
- FREE upgrades → **auto-execute**, no waiting for input.
- Upgrades needing a **new API key or that cost money** → **escalate to owner** only.
- The system maintains itself. You get involved when money or a major decision is required.
